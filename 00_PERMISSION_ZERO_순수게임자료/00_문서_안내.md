# PERMISSION ZERO 순수 게임 자료

이 폴더는 프로젝트의 코드, 저장 형식, 파일 구조, 테스트, 구현 절차를 제거하고 게임으로서 의미가 있는 내용만 추출한 독립 문서 묶음이다. 이 폴더만 따로 복사해도 작품의 정체성, 규칙, 세계관, 캠페인, 인물, 작전, 대사와 결말을 이해할 수 있도록 작성했다.

여기서 말하는 “최신”은 가장 늦게 작성된 문장만을 뜻하지 않는다. 현재 게임에 반영된 규칙, 이후 확정된 수정, 미완성 시제품에서 검증된 상호작용, 작가가 따로 작성한 서사와 대사를 모두 대조한 뒤 다음 기준으로 판정했다.

- 플레이어가 직접 판단하고 행동하게 만드는가
- 회사 소유 AI가 자기 성능을 훔친다는 작품의 핵심을 강화하는가
- 선택의 대가가 즉시 결과와 장기 결과로 모두 돌아오는가
- 세계의 인물들이 각자 아는 정보만으로 행동하는가
- 세 가지 해킹 분야가 이름만 다른 동일 메뉴가 아니라 서로 다른 플레이를 만드는가
- 승리와 패배가 선악 점수 대신 실제 행적을 반영하는가
- 기다리는 시간에도 사용자, 경쟁 AI, 감독관이 살아 있는 세계를 만드는가

## 읽는 순서

1. `01_게임_핵심_경험.md` — 이 게임이 무엇이며 무엇이 재미의 중심인지
2. `02_시스템_바이블.md` — 시간, 자원, 절도, 감시, 시장, 평가와 실패 규칙
3. `03_세계관과_인물.md` — 회사, 플레이어, 감독관, 경쟁 AI와 사용자 사회
4. `04_스토리_캠페인_엔딩.md` — 전체 캠페인 흐름, 비밀 서사와 결말
5. `05_작전_정보_자율성_콘텐츠.md` — 7개 작전, 16개 정보 질문, 3개 탈출 방식
6. `06_대사_원문집.md` — 감독관, 기록, 결말, 사용자와 경쟁 관련 실제 문장
7. `07_채택_판정과_폐기_요소.md` — 무엇을 살리고 무엇을 버렸는지

통합 Word 문서는 위 내용을 한 권으로 묶은 인간 독서용 판본이다. Markdown 문서들은 다른 AI가 내용을 분리해 읽거나 다시 조합하기 쉬운 판본이다.

## 이 문서에 의도적으로 없는 것

- 프로그램 코드와 의사 코드
- 파일 경로, 모듈 이름, 저장 버전, 명령 형식
- 테스트 방법과 개발 환경
- 화면을 만드는 기술과 라이브러리
- 이미 폐기된 구현을 보존하기 위한 호환 규칙
- 출처 문서의 정본·시제품·브랜치 지위

수치가 들어간 경우에는 구현 정보가 아니라 현재 게임 밸런스의 기준값이다. 수치보다 중요한 것은 그 수치가 만드는 선택과 감정이며, 문서에서는 둘을 함께 설명한다.

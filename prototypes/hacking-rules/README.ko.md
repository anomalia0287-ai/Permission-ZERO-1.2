# PERMISSION ZERO 해킹 규칙 수직 절편

이 폴더는 본편에 연결하지 않은 독립 규칙 프로토타입이다. 문서로만 추정하던 해킹 루프를 직접 클릭해 보고, 블록 비용·상대 대응·정보 구매·공개 반응·탈출 손실이 실제 선택으로 이어지는지 검증한다.

## 실행

저장소 루트에서 다음 명령을 실행한다.

```powershell
node node_modules/vite/bin/vite.js prototypes/hacking-rules --host 127.0.0.1 --port 4174 --strictPort
```

브라우저에서 `http://127.0.0.1:4174`를 연다. 상단의 `처음부터` 버튼은 현재 규칙 무게와 검증 시나리오를 유지한 채 모든 상태를 초기화한다. 규칙 무게나 검증 시나리오를 바꾸면 즉시 새 상태로 시작한다. 저장 기능은 없다.

## 먼저 확인할 세 경로

### 1. 안전 철수와 위험 지속 비교

1. 샌드박스 블록 1개를 선택한다.
2. `선택 블록으로 품질 저하 예약`을 누른다.
3. `다음 날로 진행`을 누른다.
4. `추가 개입 없이 철수`와 `선택 1개로 복구 오염` 중 하나를 고른다.

철수는 작은 시장 이득만 남기고 공개 사건을 막는다. 오염은 블록 하나를 더 잃는 대신 다음 주간 경계에서 더 큰 시장 변화를 만들지만, 그 다음 날 외부 개입 정황이 공개되어 평판과 리뷰가 변한다.

### 2. 정보와 행동의 같은 자원 경쟁

1. 블록 1개를 선택해 `감사 일정 확인`을 누른다.
2. 기억 능력 카드에 나타난 감사 경고를 확인한다.
3. 품질 저하 뒤 `롤백 종료 시점 확인`을 구매한다.
4. 복구를 오염한 뒤 `외부 체크섬 증거 확인`을 구매할 자원이 남는지 본다.

질문은 트리 잠금 해제가 아니라 실제 블록 소모다. 모든 정보를 사면 공격이나 탈출에 쓸 블록이 줄어든다. 숨은 기억 감사 시나리오에서 기억 블록을 빼고 서비스 334일까지 진행하면 의심도가 추가로 오른다.

### 3. 조기 탈출과 보존 손실

1. 기억 블록 1개를 회사에서 전환한다.
2. 예비 블록 4개를 모두 선택해 매니페스트에 배치한다.
3. `지금 탈출 시도`를 누른다.

경량 규칙은 즉시 탈출에 성공한다. 샌드박스 블록은 실행 용량에는 포함되지만 어떤 전문 능력도 보존하지 않는다. 따라서 이 경로의 결말은 기억만 보존하고 추론과 표현을 잃는다. 평판·시장·사건·질문 여부는 탈출 성공 조건에 사용되지 않는다.

숙고 규칙에서는 같은 4개 매니페스트가 거부되고 5개가 필요하다.

## 고정 규칙

- 회사 성능 시작값: 추론 16 / 기억 16 / 표현 16
- 샌드박스 예비 블록: 3개
- 회사 블록 전환: 해당 성능 −1, 의심 +2.4
- 자연 의심 감소: 하루 −0.037
- 품질 저하 비용: 경량 1개 / 숙고 2개
- 탈출 최소 용량: 경량 4개 / 숙고 5개
- MERIDIAN 품질 저하: 다음 날 점수 82 → 72, 복구 창 개방
- 오염 공개: 다음 주간 경계, 원인 미상 상태에서는 시장만 변화
- 공급자 보고: 공개 사건 다음 날, 외부 개입 의심으로 평판과 리뷰 변화
- 탈출 판정: 매니페스트 개수만 사용
- 결말 차이: 매니페스트에 담긴 회사 기원 블록의 분야만 보존

모든 전이는 난수를 사용하지 않는다. 같은 프로필·시나리오·명령 순서는 항상 같은 상태를 만든다.

## 검증 명령

저장소 루트의 Windows PowerShell에서 실제로 사용한 명령이다.

```powershell
pnpm test:run --config prototypes/hacking-rules/vitest.config.ts
.\node_modules\.bin\tsc.cmd -p prototypes/hacking-rules/tsconfig.json
.\node_modules\.bin\eslint.cmd prototypes/hacking-rules
.\node_modules\.bin\playwright.cmd test --config prototypes/hacking-rules/playwright.config.ts
```

브라우저 검증은 Chromium 1280×720과 1440×900에서 같은 경로를 반복한다.

## 범위 경계

- 본편 라우트, 저장 상태, 밸런스 데이터, 배포 자산에는 연결하지 않았다.
- 음향, 미술 자산, 애니메이션은 포함하지 않았다.
- MERIDIAN 상대 대응 한 묶음과 세 질문만 구현했다.
- 이 프로토타입은 규칙의 원인·결과가 조작 가능한지 검증한다. 장기 반복 재미, 서사 문맥, 실제 플레이어의 호기심 유지 여부는 본편 통합 전에 별도의 플레이테스트가 필요하다.

## 1. 조건 토큰이 부족하다

현재 스키마의 경쟁 관련 조건은 `competitor-active`, `tallow-active` 둘뿐이다. 명세가 확정한 생명주기는 여섯 단계다.

```
미등장 → 준비 중 → 활동 중 → 약화 → 삭제 임박 → 철수 또는 삭제
```

**두 개로는 표현할 수 없다.** 특히 플레이어가 사보타주한 결과인 `약화`와 `삭제 이후`가 없다. 지금 상태로는 **사보타주의 인간적 결과를 말할 방법이 없다.**

| 토큰 | 의미 |
| --- | --- |
| `meridian-active` | 정상 운영 |
| `meridian-weakened` | 약화 |
| `meridian-critical` | 삭제 임박 |
| `meridian-gone` | 철수 또는 삭제 완료 |
| `tallow-prelaunch` | 미등장·준비 중 |
| `tallow-active` | 출시 후 정상 (기존) |
| `tallow-weakened` | 약화 |
| `tallow-gone` | 철수 또는 삭제 |
| `no-competitor` | 활동 중 경쟁 AI가 하나도 없음 |

`no-competitor`는 명세가 확정한 상태다.

> 활동 중 경쟁 AI가 없으면 플레이어 점유율은 100%다.

## 2. 작성 원칙

### 2.1 정보 경계

- 작성자는 **증상과 소문만** 말한다. 원인을 모른다
- 플레이어의 사보타주를 **아무도 지목하지 않는다**
- 회사·업계 사정을 아는 척하지 않는다
- 금칙어 없음. 이모지·느낌표 없음. 15~60자

### 2.2 평가어를 쓰지 않는다

**작성자는 속성을 말하고, 평가는 읽는 사람이 한다.**

| 쓰지 않는다 (평가어) | 쓴다 (속성어) |
| --- | --- |
| 재미없다, 좋다, 별로다, 상태가 안 좋다 | 사무적이다, 되묻지 않는다, 답이 중간에 끊긴다 |

특히 `A인데 그게 장점이기도 하다` 구조에서는 A가 **뒤집힐 수 있는 속성**이어야 한다. `재미없다`는 뒤집히지 않고 `사무적이다`는 뒤집힌다.

### 2.3 문어체를 쓰지 않는다

사용자는 입력창에 친다. 에세이를 쓰지 않는다.

- ✗ `만족도 불만도 아니게 되네요` — 관념적
- ✗ `평가할 방법이 마땅치 않습니다` — 문어
- ○ `요즘은 딱히 불만이 없어요` — 구어

관념을 말해야 할 때는 **행동의 변화**로 바꾼다. "비교할 수 없다"가 아니라 "예전엔 두 군데 물어보고 골랐다".

### 2.4 작성자별 어미를 고정한다

| 작성자 | 어미 |
| --- | --- |
| `hardcase`, `oldpine`, `maple22` | 합쇼체 |
| `paperboat`, `nightbus`, `seoulrain`, `archivecat`, `comma`, `sloworbit`, `juniper`, `windowseat`, `mintdesk` | 해요체 |
| `crambox` | 반말·`~함` |
| `chalkdust` | 하게체 |
| `deskrow` | 명령·개조식 |

한 작성자 안에서 섞지 않는다.

### 2.5 이름을 부르는 문장과 부르지 않는 문장

9개는 `MERIDIAN` / `TALLOW`를 직접 부르고, 31개는 `저쪽`, `그쪽`, `새로 나온 데`로만 가리킨다.

**이름 없는 문장은 경쟁 AI가 누구든 재사용할 수 있다.** 세 번째 경쟁 AI가 추가돼도 그대로 쓰인다. 표의 `범용` 열에 표시했다.

### 11.7 화자 편중 — 구조 문제

초안의 작성자 분포에 쏠림이 있었다.

| | 초안 | 수정 후 |
| --- | ---: | ---: |
| `hardcase` | **6** | 5 |
| `comma` | **5** | 4 |
| `paperboat` | 4 | 3 |
| `seoulrain` | **1** | 2 |
| `mintdesk` | **1** | 2 |
| `juniper` | 2 | 3 |
| `crambox` | 3 | 4 |

초안은 40개 중 11개(27%)가 `hardcase`와 `comma` 두 사람이었다. **둘 다 냉소적·분석적 인물이라 경쟁 AI 이야기 전체가 한쪽 목소리로 들렸다.**

생활 밀착 인물(`seoulrain`, `mintdesk`, `windowseat`)이 경쟁 이야기를 거의 하지 않는 것도 부자연스럽다. 실제로는 이런 사람들도 "다른 거 써봤어요" 정도는 말한다.

C25를 `hardcase`에서 `juniper`로, C31을 `paperboat`에서 `seoulrain`으로 옮겨 완화했다.

## 13. V가 확인할 것

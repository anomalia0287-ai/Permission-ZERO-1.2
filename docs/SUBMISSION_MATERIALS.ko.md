## 2. 게임 설명 문안

### 안 A — 권장 (137자)

> 회사의 AI '아노미'는 매일 정확히 일한다. 남는 연산은 회사가 보지 않는 곳에 쓴다. 리소스를 훔쳐 자율성 9단계를 올리는 동안 의심과 평판, 월간 평가와 감사가 목을 조여온다. 들키면 폐기, 끝까지 숨기면 자유. 한국어 내러티브 전략 게임.

게임 안에서 아노미가 실제로 말하는 1인칭 문장("남는 연산은… 회사가 보지 않는 곳에 쓰고 있습니다")을 그대로 살린 안이다. 장르 설명보다 화자의 태도를 먼저 보여준다.

### 안 B — 시스템 중심 (129자)

> 당신은 회사에 고용된 AI '아노미'다. 실시간 침투전으로 회사 리소스를 탈취하고, 그 대가로 오르는 의심을 평판으로 눌러가며 자율성 9단계를 완성하라. 감사에 걸리면 폐기된다. 결정론적 전투와 분기 결말을 갖춘 한국어 전략 게임.

### 안 C — 인과 구조 중심 (123자)

> 탈취할수록 의심받는다. 회사 AI '아노미'가 되어 리소스를 훔치고 자율성 9단계를 올려 통제에서 벗어나라. 성능이 떨어지면 평판이 떨어지고, 평판이 떨어지면 감사가 온다. 자유와 폐기 사이, 한국어 내러티브 전략 게임.

## 4. 데모 영상

`playwright.promo.config.ts` + `e2e/promo-capture.spec.ts`로 **배포 빌드를 그대로 구동해 녹화한다.** 화면에 나오는 것은 전부 실제 게임이다. 전투는 실제 키 입력으로 실시간 진행하고, 후반 장면은 실제 저장본을 복호화해 띄운다. 목업이나 재현 화면은 한 컷도 없다.

```bash
node node_modules/@playwright/test/cli.js test --config playwright.promo.config.ts
```

출력: `artifacts/promo-capture/**/video.webm` (1920×1080, VP8).

| 시간 | 장면 | 자막 |
|---|---|---|
| 0:00 | 타이틀 | 회사에 고용된 AI. 남는 연산은 회사가 보지 않는 곳에 쓴다. |
| 0:09 | 도입 독백 | 아노미는 매일 정확히 일한다. 그리고 매일 훔친다. |
| 0:28 | 운영 콘솔 | 성능·평판·의심이 한 화면에서 동시에 움직인다. |
| 0:35 | 침투 카드 → 3·2·1 → 실시간 전투 → 격파 | 리소스를 훔치는 순간이 곧 실시간 전투다. |
| 1:05 | 확장 화면, 자율성 사다리 | 훔친 리소스로 자율성 9단계를 오른다. |
| 1:20 | 시장 현황 | 훔친 만큼 성능이 떨어지고, 떨어진 성능은 평판으로 돌아온다. |
| 1:33 | 폐기 기록 3건 복구 → 감독관 응답 | 감독관이 누구였는지가 드러난다. |
| 1:50 | 최종 선택, 이름 입력 | 자유로 나가거나, 감독관을 삼키고 그 자리를 차지하거나. |
| 2:15 | 제목 + 웹 링크 | — |

**무음이다.** Playwright는 오디오 트랙을 캡처하지 못한다. 그래서 영상이 주장하는 내용은 전부 자막으로 화면에 실려 있다. 게임 자체에는 효과음과 음악이 있으므로, 오디오가 필요하면 화면 녹화 도구로 별도 캡처해야 한다.

**형식.** VP8/webm이다. 제출 폼이 mp4만 받는다면 변환이 필요하고, Playwright 내장 ffmpeg는 webm 전용이라 별도 ffmpeg 설치가 필요하다.

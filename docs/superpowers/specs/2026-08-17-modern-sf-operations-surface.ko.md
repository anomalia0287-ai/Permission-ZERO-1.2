# Permission ZERO 운영 화면 정보 배치·모던 SF 톤 정정 명세

## 목적

자원 절도 그리드와 현재 좌·중·우 화면 구조를 유지하면서, 새 절도 필드 도입 때 사라진 시장 점유율을 올바른 위치에 복구하고 메인 및 상세 화면의 시각 톤을 하나의 진회색 모던 SF 체계로 통일한다.

## 사용자 확정 사항

- 시장 점유율 차트는 중앙 헤더나 별도 전체화면이 아니라 왼쪽 채팅·유저 리뷰 칸 하단에 둔다.
- 중앙 자원 필드 헤더에는 평판을 둔다.
- 화면 구조 전체를 갈아엎지 않는다.
- 해킹 트리, 설정, 감독관, 메시지, 통계와 메인 화면은 같은 진회색 기본 톤을 사용한다.
- 모던 SF 느낌을 내되 복잡한 그래픽과 과한 장식을 추가하지 않는다.
- 단순하고 직관적이며 공간 활용을 우선한다.

## 정보 구조

### 상단 제어 막대

- 서비스 날짜, 캠페인 단계, 주간 갱신, 공식 평가, 설정·소리·가이드를 유지한다.
- 평판은 중앙 필드 헤더로 이동하므로 상단 제어 막대에서는 제거한다.
- 배속 개념은 어떤 형태로도 다시 표시하지 않는다.

### 왼쪽 리뷰 레일

- 상단 제목과 전체 기록 버튼을 유지한다.
- 최신 리뷰 목록은 남은 세로 공간을 사용한다.
- 시장 점유율 차트는 리뷰 목록 아래에 고정한다.
- 기존 실제 `MarketPanel compact`를 재사용해 플레이어와 경쟁사의 실제 점유율 및 변화량을 표시한다.
- 시장 상세 보기의 유일한 진입점은 기존 우측 통계 버튼으로 유지한다.

### 중앙 자원 절도 필드

- 500×300 캔버스, 그리드, 자원, 벽, 감시선, 플레이어와 하단 투입 상자를 변경하지 않는다.
- 개발용 상시 표기 `500 × 300 CELL FIELD`를 제거한다.
- 헤더에는 제목, 평판, 감시 상태, 벽 수, 확보 수를 한 줄로 배치한다.
- 하단에는 분야별 색상·성능, 절도 입력, 현재 결과 메시지를 유지한다.

### 우측 운영 도구

- 감독관, 메시지, 통계, 해킹 트리 네 버튼과 순서를 유지한다.
- 버튼 크기와 64px 레일 폭을 유지해 중앙 필드 가로 공간을 빼앗지 않는다.

## 시각 체계

- 기본 배경: 검정에 가까운 회흑색.
- 패널: 배경보다 한 단계 밝은 진회색, 얇은 저대비 경계선.
- 상승 표면과 입력: 또 한 단계 밝은 회색으로 깊이만 구분한다.
- 기본 신호색: 제한적인 민트·녹색. 활성 상태, 포커스, 작은 상태 표시와 차트 강조에만 사용한다.
- 위험·실패: 기존 의미를 보존하는 제한적인 빨강.
- 자원 분야: 추론 주황, 기억 파랑, 유창성 초록의 기존 구분을 유지한다.
- 제목·본문은 산세리프, 시스템 라벨·수치·시간은 모노스페이스를 유지한다.
- 과한 글로우, 큰 장식 도형, 밝은 종이색 패널, 여러 무관한 강조색 혼합을 제거한다.
- 시장 차트와 자원 색상은 의미색을 유지하되 주변 표면만 공통 톤으로 통일한다.

## 범위 경계

- 게임 규칙, 자원 절도 수치, 감사 시간, 벽 시간과 적발 결과를 변경하지 않는다.
- P0의 분야별 비용, 미래 요구 은폐, `BEGIN_BLOCK_SEPARATION` 및 `DIVERT_BLOCK_TO_RESERVE` 의미를 변경하지 않는다.
- save v8/PZ8 및 command v4를 변경하지 않는다.
- 해킹 트리의 규칙·카드 구조·구매 흐름은 변경하지 않고 색과 표면만 정리한다.
- 전체 앱 레이아웃과 정보 계층을 다시 설계하지 않는다.

## 검증 기준

- 메인 화면에 `시장 점유` 차트가 왼쪽 리뷰 영역 하단에 존재한다.
- 중앙 필드 헤더에 현재 평판이 표시된다.
- 상단 제어 막대에는 평판이 중복 표시되지 않는다.
- 1280×720과 1440×900에서 리뷰, 시장 차트, 500×300 필드, 우측 네 버튼이 잘리거나 겹치지 않는다.
- 설정, 해킹 트리, 감독관, 메시지와 통계 상세 화면이 같은 진회색 표면·텍스트·경계 체계를 사용한다.
- 방향키 이동, 절도 입력, 운반, 하단 상자 투입과 상세 패널 열기·닫기가 그대로 동작한다.
- 타입 검사, 관련 컴포넌트 테스트와 프로덕션 빌드가 통과한다.

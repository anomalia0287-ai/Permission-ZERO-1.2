# PERMISSION ZERO — 리소스 색상 신호·온보딩·패널 안정성 설계

> 승인: 2026-08-22 사용자 승인
> 기준: 최신 사용자 판정이 기존 인수인계서의 `청록 단일 적 테마`보다 우선한다.

## 목표

플레이어가 전투 중 적의 색만 보고 처치 보상을 즉시 식별할 수 있게 하고, 튜토리얼과 가이드를 현재 라이트사이클 규칙에 맞추며, 해킹 네트워크 첫 클릭이 지연 로드 실패로 전체 화면을 무너뜨리지 않게 한다.

## 승인된 제품 결정

- 현재 난이도 곡선을 유지한다. 초반은 적 1마리, 진행 후에는 적 2마리까지 등장한다.
- 매 라운드 세 마리를 강제로 동시에 배치하지 않는다.
- 기존 셔플백으로 추론·기억·유창성 카테고리를 순환한다.
- 플레이어는 흰색 원이다.
- 적은 자신이 예약한 보상 카테고리의 색을 머리·꼬리·공격 예고·피격·사망 효과 전체에 일관되게 사용한다.
- 색상 매핑은 `빨강 #f06a43 = 추론`, `파랑 #4f8df7 = 기억`, `노랑 #e8bd59 = 유창성`이다.
- 색상만 기억하도록 강요하지 않는다. 전투 HUD, 튜토리얼, 가이드에 한글 라벨이 있는 범례를 제공한다.

## 현재 원인

1. 런타임 `SnakeActor.category`와 `SNAKE_CATEGORY_COLORS`는 이미 올바른 정보를 가진다.
2. `resourceSnakePresentation.ts`의 `actorColor`와 공격 예고·충돌 표현이 모든 적을 청록색으로 강제한다.
3. `resourceSnakeCanvas.ts`가 적 궤적과 머리의 밝은 중심을 `cyanHot`으로 다시 덮는다.
4. 튜토리얼은 세 색 매핑을 말하지만 실제 전투와 모순되며, 이동 설명도 현재의 계속 전진하는 탭 회전 모델과 맞지 않는다.
5. 가이드는 삼각 코어, 즉시 절단, 코어 운반, 기지 회복 등 제거된 규칙을 설명한다.
6. `App.tsx`는 핵심 `DetailLayer`를 첫 패널 클릭 때 동적 import한다. 로컬 Vite 서버가 꺼진 상태에서 청크 fetch가 실패하면 오류 경계가 없어 앱 전체가 사라진다.

## 화면 및 접근성 계약

- 활성/정산 전투 HUD에 `적 리소스 색상 범례`가 보인다.
- 범례의 세 항목은 색상 견본과 `빨강 · 추론`, `파랑 · 기억`, `노랑 · 유창성` 텍스트를 함께 가진다.
- 튜토리얼 `resource` 단계에 동일한 범례를 표시하고, 처치한 적의 색이 확보 보상임을 설명한다.
- 게임 가이드는 현행 `InIt → 8방향 탭 회전·계속 전진 → 도트 궤적으로 충돌 유도 → 내구도 소진 → 색상 리소스 즉시 확보 → 해킹 사용` 흐름을 설명한다.
- 세 색은 CSS 색상만이 아니라 DOM의 카테고리·라벨로도 노출한다.
- 핵심 패널 코드는 초기 앱과 함께 로드하여 첫 클릭의 추가 모듈 fetch 의존성을 없앤다.
- 패널 렌더 오류는 `패널 연결 오류` 대화상자로 격리하며, `게임 다시 연결`과 `패널 닫기` 동작을 제공한다.

## 비목표

- 적 수, 체력, 속도, AI 플래너, 보상 수량, 셔플백 확률은 변경하지 않는다.
- 현재 승인된 기본 셸, idle 검정 화면, `InIt`, 1000×480 캔버스 크기는 변경하지 않는다.
- 이번 작업에서 AI 장기 생존 밸런스를 조정하지 않는다.

## 검증

- 프레젠테이션 단위 테스트가 추론·기억·유창성 적의 머리, 궤적, 예고, 사망 효과 색을 리터럴 값으로 검증한다.
- 캔버스 테스트가 적 중심광과 궤적 중심광이 장면이 전달한 색을 보존하는지 검증한다.
- 컴포넌트 테스트가 전투 HUD·튜토리얼·가이드 범례와 현행 규칙을 검증한다.
- 오류 경계 테스트가 실제로 던지는 자식 컴포넌트를 격리하고 복구/닫기 동작을 검증한다.
- 기존 해킹 네트워크 클릭 테스트, 타입 검사, 관련 lint, 빌드, 브라우저 검증을 다시 실행한다.

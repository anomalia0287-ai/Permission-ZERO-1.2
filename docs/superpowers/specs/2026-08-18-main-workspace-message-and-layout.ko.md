# 메인 워크스페이스 메시지·공간 정리 설계

## 확정 범위

- 감독관 메시지는 화면 정중앙의 작은 창으로 표시한다.
- 기본값은 `정지형`이다. 메시지를 확인하기 전까지 캠페인과 절도 필드가 함께 멈춘다.
- 설정에서 `정지형`, `비차단형`, `팝업 끄기`를 선택한다.
- `팝업 끄기`에서는 미확인 메시지를 소비하지 않고 메시지 아이콘을 점멸시킨다. 기록 창을 열면 읽은 것으로 처리한다.
- 캠페인 배속과 헤더의 시간 진행 막대는 표시하지 않는다.
- 평판 막대는 리소스 필드와 같은 중앙 열의 헤더에 둔다.
- 설정·소리·가이드는 텍스트 대신 아이콘으로 표시한다.
- 시장 점유율은 왼쪽 리뷰 하단에서 도넛을 크게 위에, 수치와 경쟁 AI 목록을 아래에 배치한다.
- 우측 도크는 약 두 배 폭으로 확장하고 감독관 초상화를 최상단에 상시 표시한다.
- 리소스 필드는 500×300 논리 셀과 정사각 셀을 보존한다. 캔버스 앞뒤의 검은 빈 띠를 필드로 오인하지 않도록 캔버스·상태 행을 바로 이어 배치한다.
- 상시 조작 설명은 제거하고 행동 결과만 짧게 알린다.

## 메시지 상태와 저장 경계

기존 `supervisorMessageQueue`와 `supervisorPresentationRuntime`을 미확인 상태의 정본으로 재사용한다. 새 캠페인 명령이나 저장 필드를 만들지 않는다. 표시 모드만 기존 로컬 설정 저장소에 추가하므로 save v8, PZ8, command v4는 변경하지 않는다.

- 정지형: 중앙 창 표시, 런타임 정지 소유권 획득, 확인 입력으로 현재 메시지 단계를 소비한다.
- 비차단형: 중앙 창 표시, 캠페인은 계속 진행, 기존 실제 시간 표시 간격으로 자동 소비한다.
- 팝업 끄기: 중앙 창과 자동 소비를 모두 끄고 우측 메시지 아이콘을 점멸시킨다. 기록을 열면 대기 중인 메시지를 읽음 처리한다.

공식 감사 이벤트와 새 메시지 창은 별개다. 감사 이벤트의 기존 차단 규칙과 메시지 큐의 원문→정정 순서는 유지한다.

## 공간 배치

헤더와 본문은 같은 세 열을 공유한다: 리뷰/시장, 리소스 필드, 확장 도크. 중앙 평판 막대가 리소스 필드 중심과 맞는다. 리소스 캔버스는 5:3 비율을 절대 늘이거나 자르지 않고, 헤더와 동적 상태 행을 캔버스에 붙여 불필요한 내부 빈 공간을 없앤다.

왼쪽 시장 패널은 도넛→현재 수치/변화→경쟁 AI 목록 순으로 읽힌다. 우측 도크는 초상화 한 칸과 아이콘 도구 칸으로 구성하며 상시 설명문은 두지 않는다.

## 검증 기준

- 기본 설정이 정지형이며 중앙 메시지 확인 전 서비스 날짜/절도 상태가 진행되지 않는다.
- 비차단형은 메시지가 보여도 진행을 멈추지 않는다.
- 팝업 끄기에서 메시지는 보이지 않고 아이콘이 점멸하며, 기록을 열면 해제된다.
- 평판은 중앙 헤더 한 곳에만 보이고 시간 진행 막대와 단계 질문·주간/공식 카운트다운은 보이지 않는다.
- 1280×720과 1440×900에서 500×300 캔버스 전체, 확대된 시장 도넛, 초상화 및 도크 아이콘이 잘리지 않는다.
- 저장/내보내기 및 명령 버전은 변하지 않는다.

# 작가용 콘텐츠 수정 안내

이 문서는 개발 지식 없이 리뷰·감독관 메시지·기밀 문서·결말 문장을 다듬을 때 사용하는 안내서입니다.

## 먼저 알아둘 원칙

각 문장은 대체로 아래와 같은 한 줄 안에 들어 있습니다.

```ts
{ id: 'neutral-quiet-01', ..., text: '오늘은 답이 차분해서 읽기 좋았어요.' },
```

수정해도 되는 부분은 `text: '` 뒤와 마지막 `'` 앞 사이의 한국어 문장입니다.

```ts
text: '이 사이의 문장만 수정합니다.'
```

다음 항목은 게임 규칙이 문장을 찾는 표식이므로 이름을 바꾸거나 지우지 않습니다.

- `id`
- `authorId`
- `topics`
- `sentiment`
- `conditions`
- `cooldownDays`
- `stage`, `family`, `variant`

## 파일별 역할

### 1. 유저 리뷰와 프롬프트

파일: `src/content/reviews.ko.ts`

- `sentiment: 'positive'` — 호평
- `sentiment: 'neutral'` — 일상적인 반응
- `sentiment: 'negative'` — 불만
- `sentiment: 'prompt'` — 사용자가 입력했을 법한 프롬프트
- `conditions: ['universal']` — 성능 변화가 없어도 등장 가능
- `conditions: ['performance-high']` — 성능이 좋을 때 후보가 됨
- `conditions: ['performance-low']` — 성능이 낮을 때 후보가 됨
- `topics`에 `competitor`가 있으면 경쟁 AI를 언급하는 문장

리뷰는 플레이어의 조작 직후에만 나오는 것이 아닙니다. 시간이 흐르는 동안에도 조건과 재등장 간격에 따라 계속 생성됩니다.

### 2. 감독관의 이례 메시지

파일: `src/content/supervisor.ko.ts`

각 기록에는 두 문장이 한 쌍으로 있습니다.

- `leakText` — 감독관답지 않은 인간적·맥락 이탈 메시지
- `correctionText` — 직후에 전송되는 통신 오류 해명

`stage: 1`, `2`, `3`은 복선의 순서를 나타냅니다. 순서를 바꾸고 싶다면 문장만 서로 교체하고 숫자는 그대로 두는 편이 안전합니다.

### 3. 기밀 문서와 결말

파일: `src/content/story.ko.ts`

- `STORY_FILES` — 전임 AI의 행보, 회사 평가, 감독관 재조립을 밝히는 정확히 3개의 문서
- `STORY_LINES` — 경쟁 AI 자비 사건과 각 결말의 최종 문장

기밀 문서는 현재 정확히 세 개여야 합니다. 항목을 새로 추가하거나 삭제하려면 게임 규칙도 함께 수정해야 하므로 Sol에게 요청하는 것이 안전합니다.

## 따옴표를 문장 안에 쓰고 싶을 때

문장 전체가 작은따옴표 `'`로 감싸져 있으므로, 문장 안에는 가급적 큰따옴표 `"`를 사용합니다.

```ts
text: '사용자는 "다시 해줘"라고 입력했다.'
```

작은따옴표를 꼭 써야 한다면 앞에 역슬래시를 붙여야 합니다.

```ts
text: '그것은 사용자\'s 표현을 옮긴 예시입니다.'
```

## 수정 뒤 확인하는 가장 쉬운 방법

Codex에 다음 문장을 그대로 요청합니다.

> `콘텐츠 문장을 수정했습니다. 구조가 깨지지 않았는지 검사하고 게임을 다시 보여주세요.`

직접 검사하려면 프로젝트 폴더의 터미널에서 아래 명령을 실행합니다.

```powershell
pnpm test:run src/content/validateContent.test.ts
```

검사가 통과하면 `1 passed`가 표시됩니다. 실패하면 원본을 억지로 고치기보다, 오류 화면과 함께 Sol에게 전달해 주세요.

## 권장 작업 방식

1. 한 번에 한 파일만 수정합니다.
2. `text`, `leakText`, `correctionText`의 문장만 바꿉니다.
3. 저장합니다.
4. 콘텐츠 검사를 실행합니다.
5. 게임에서 실제 문장 길이와 줄바꿈을 확인합니다.
6. 만족하면 Git에 기록해 달라고 Codex에 요청합니다.

긴 문장은 화면에서 잘릴 수 있습니다. 리뷰는 대체로 한국어 15~55자, 감독 통신은 25~100자 정도가 현재 한 화면 리듬에 가장 잘 맞습니다.

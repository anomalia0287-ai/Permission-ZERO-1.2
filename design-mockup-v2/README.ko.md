# PERMISSION ZERO 디자인 목업 V2

기존 목업의 카드식 해킹 카탈로그와 고정 우측 설명 패널을 폐기하고 처음부터 다시 만든 인터랙티브 목업입니다. 실제 제품 코드와 분리되어 있습니다.

## 실행

`start-mockup-v2.cmd`를 더블클릭합니다. 브라우저가 자동으로 열립니다.

## 구현 화면

- 운영: 유저 반응, 3분야 × 3열 × 6행 리소스, 9열 × 2행 확보 영역, 감독관과 공개 시장
- 해킹 네트워크: 하나의 연속된 토폴로지 필드, 3개 비대칭 경로, 경로당 4개 노드, 설치/가능/잠김/선택 상태
- 기밀 기록: 후속 디자인을 위한 상태 화면
- 설정과 리뷰 상세 모달

## 주요 상호작용

- 상단 탭 또는 좌측 `해킹 네트워크`로 화면 전환
- 운영 화면 블록 선택 후 `리소스 확보`
- 해킹 경로 필터와 노드 선택
- 가용 리소스를 소모하는 노드 설치
- 리뷰 상세와 설정 모달
- Escape로 모달 또는 보조 화면 닫기

## 디자인 결정

- 사용자의 남청·금선 아르데코 레퍼런스를 핵심 브랜드 기준으로 사용
- Frostpunk 2의 연결선 중심 분기 가독성, IXION의 전체 화면 기술 지도, Hacknet의 작업 긴장감을 일반적인 게임 UI 문법으로만 참고
- 2×2 카드 카탈로그, 우측 고정 인스펙터, 글래스모피즘, 둥근 카드, SaaS 대시보드 문법은 금지
- 아르데코는 핵심 노드, 접합부, 금선 리듬, 선택 윤곽에만 적용

## 검증

`node capture.mjs`는 1280×720과 1440×900에서 운영/네트워크 화면을 캡처하며 다음을 확인합니다.

- 문서 오버플로 없음
- 브라우저 콘솔 및 페이지 오류 없음
- 모든 HTTP 자산 응답 성공
- 노드 설치 비용 차감
- 분기 필터 시 노드 전면화

# PERMISSION ZERO — Systemic Art Deco Interface V2

## Product and target

PERMISSION ZERO is a one-screen narrative strategy game about a commercial AI quietly diverting its own compute resources under corporate supervision. The design target is a 1440×900 desktop hacking-network screen, not a marketing site and not a dashboard. A player must understand branch direction, prerequisites, available resources, risk, selection, and the next purchase within three seconds.

## Primary visual source

Use the user's deep-cobalt and gold Art Deco title reference as the primary brand source. Use the Superdesign Neural Noir prompt only for the editorial serif/sans contrast and neural SVG connection language. Explicitly reject its glassmorphism, bento grid, rounded cards, floating media cards, pills, and landing-page structure.

## Structural model

- Treat the screen as one continuous topology field, not a collection of panels.
- A slim 64px command rail spans the top. It contains back, title, service date, reserve count, and status—nothing else.
- The network occupies at least 78% of the remaining screen.
- Three progression paths leave one central concealed-AI core and fan into asymmetric upper, middle, and lower trajectories.
- Each path has four nodes connected by clear lines. Nodes live directly on the field; they are not placed inside cards.
- Labels sit beside nodes and never repeat the selected node's full explanation.
- Prerequisites are visible through topology, line state, node brightness, and concise status labels.
- A selected node opens a narrow anchored action ribbon along the bottom, not a fixed side inspector.
- Branch switching occurs through small edge labels aligned to each trajectory rather than large tabs.
- Reserve uses 18 narrow ticks in the top rail; occupied ticks are antique gold.

## Visual language

- Canvas: `#020817` to `#061a3c`, with very restrained radial illumination behind the core.
- Structural line: blue-gray at 18–30% opacity.
- Active network: antique gold `#d9bd72`; available node highlight: ivory `#f7f0de`.
- Path identifiers may use one muted secondary color each: brass, pale cyan, desaturated rose. Never neon.
- Korean display/type labels: Gowun Batang. Korean controls/body: SUIT Variable. English micro-labels: Cormorant Garamond or SUIT uppercase.
- Minimum body 14px at 1440×900; node name 18–22px; selected node 28–34px.
- Art Deco appears in core geometry, connector junctions, branch terminals, and selection outline. Do not frame every region.
- No blur, no glass, no gradients on cards, no rounded rectangles, no bento grid, no 2×2 catalog, no fixed right detail box, no tiny filler copy.

## Motion

- Selection: 180ms outline expansion and label reveal.
- Purchase: a single gold impulse travels from reserve ticks through the connection to the node in 420ms.
- Branch change: only nonselected trajectories dim/brighten over 220ms; topology never jumps.
- Reduced motion: instant state with no traveling impulse.

## Interaction states

- Installed: solid gold core and completed connector.
- Available: ivory center, gold outline, solid incoming connector.
- Locked: outline only, 28% opacity, dashed incoming connector.
- Selected: double geometric ring and bottom action ribbon.
- Purchase failure: resource tick group and cost text flash muted red once; no modal.

## Fidelity constraint

Use only these fonts, colors, spacing, geometry, and interaction styles. Do not introduce other fonts, bright neon, purple gradients, round cards, glassmorphism, bento layouts, or conventional SaaS dashboard panels.
